Skill guide

Bootstrap a full design workspace from screenshots or Figma.

Start with an empty folder, feed in design references, and let the skill scaffold a Storybook-first workspace with foundation guides, token work, and visual parity checks.

Typical starting point

node /path/to/create-design-workspace/scripts/bootstrap-design-workspace.mjs \
  --target "./my-ui-workspace" \
  --screenshot "./reference/home.png"

What this skill helps with

It turns design references into a workspace the agent can keep building.

The point is not just to create files. It is to move the project from input gathering to a usable system: scaffold, analyze, document, build, and compare.

How to start

A practical first run takes only a few steps.

The skill is designed for a clean beginning: use a new folder, provide a design source, bootstrap the workspace, then continue through the guided flow.

    Outputs and ownership

    What lives in the workspace after bootstrap.

    This skill creates a project skeleton that is meant to be continued by Cursor, Claude Code, or Codex. It keeps the handoff explicit so the next step is not guesswork.

    What it is not for

    This skill is for new UI-to-code projects, not in-place patching.

    The workflow assumes a fresh workspace and a design source. It is intentionally opinionated so the bootstrap path stays predictable.

    Avoid these mistakes

    Do not drop it into an existing app root with unrelated code. Do not start without screenshots or a Figma URL. If you want Figma-first automation, make sure the workspace has `FIGMA_PAT` or `FIGMA_AUTH_MODE=connector` before Phase 0.
