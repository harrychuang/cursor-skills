# Product Change Workflow

1. Update `product/PRD.md`
2. Read `start-here/ACCURACY_CONTRACT.md` and record source mode, assumptions, missing context, and visual acceptance threshold
3. Sync or edit `product/PRODUCT_SPEC.json`
4. Sync or edit `product/FEATURE_MANIFEST.json`
5. Update `product/SCREEN_MANIFEST.json` if screen scope changed
6. Implement only after the written requirements match the intended change
7. Record remaining visual variance after parity checks
