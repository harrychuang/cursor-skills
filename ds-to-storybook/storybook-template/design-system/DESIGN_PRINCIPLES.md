# Design Principles

| Principle | Evidence | Implementation Rule |
|---|---|---|
| Preserve dense operational scanning | E-001, E-004, E-005 | Use compact bars, fixed numeric columns, and flat rows. Do not expand spacing for visual polish unless a future reference shows it. |
| Keep dark surfaces layered, not decorated | E-001, E-003, E-005, E-007 | Use `#1E1E1E`, `#252525`, `#333333`, and black as functional depth levels. Avoid gradients, glow effects, and decorative panels. |
| Keep stock context in the app bar | E-081, E-003, E-035 | Use stock-title navigation as a Top App Bar variant with centered stock identity, compact arrows, and 27px action icons. Do not create a separate decorative stock header. |
| Keep standalone stock identity labels compact | E-087, E-005, E-071 | Use Stock Label only for small display-only stock context markers with code plus name. Do not replace full quote rows, portfolio sheet identity rows, valuation labels, or main-force trade tags with this compact label. |
| Keep stock feed cards commentary-led | E-088, E-084, E-005 | Use Stock Card only for stock-specific social/discovery commentary with sentiment, author metadata, and body copy. Do not replace quote rows, quote tiles, event rows, popups, empty states, bubbles, or broker rows with this feed card. |
| Keep similar-stock results comparison-led | E-094, E-070, E-088, E-005 | Use Similar Stock Card for compact comparison results with stock quote summary, similarity score, add-to-watchlist action, and feature summaries. Do not replace it with the Similar Stock Button CTA, Stock Card feed/commentary anatomy, quote rows, quote tiles, or portfolio-fit sheet chrome. |
| Keep return calendars market-led | E-089, E-093, E-006 | Use Stock Calendar for monthly return scanning with fixed 57x62 Stock Calendar Cells, five trading-day columns, a weekly summary column, red-up/green-down market washes, zero/no-market states, and border-only selected cells. Do not treat calendar red/green as error/success or replace it with event/relative-date components. |
| Keep trend-analysis filters local and gray | E-090, E-046, E-061 | Use Trend Analysis Header for local chart/analysis period switching with a muted gray filled selected range and separate custom outline action. Do not replace it with market tabs, orange event options, global buttons, or portfolio preference headers. |
| Keep asset trend charts data-led | E-091, E-090, E-045 | Use Asset Trend Chart for the chart body beneath trend-analysis controls, preserving the compact total-asset/daily-P&L summary, orange area-line series, muted axes, and selected-date marker. Do not replace it with a raised profit summary card, donut analysis panel, quote mini chart, Global Bubble tooltip, or generic chart card. |
| Keep signed bar charts baseline-led | E-092, E-091, E-045 | Use Trend Analysis Bar Chart when a local trend-analysis block needs red/green values above and below a zero baseline. Preserve the 375x138 histogram geometry, 37px y-axis column, 298px plot, 8px square bars, and 46px positive/negative bands. Do not merge it into the orange Asset Trend Chart or the raised Portfolio Profit Summary chart body. |
| Keep global actions compact and explicit | E-083, E-026, E-056, E-069 | Use the global Button only for app-wide primary fill/outline actions. Preserve explicit pressed and disabled color treatments instead of opacity-only states. |
| Encode market state with domain colors | E-006 | Use red for Taiwan stock-up values and green for stock-down values. Do not remap red to error or green to success in market data contexts. |
| Align numbers for fast comparison | E-005 | Prices and changes use fixed right-aligned columns. Keep amount, delta, percent, and chart positions stable across rows. |
| Keep quote tiles grid-specific | E-084, E-005, E-074 | Use Realtime Quote Tile for compact 170x148 watchlist grids with chart/weather bottom content. Do not stretch tiles into list rows or replace Realtime Quote Row with card tiles. |
| Keep main-force signals row-bound | E-075, E-076, E-077 | In `主力籌碼` views, use one flat 61px row with compact weather, volume, rate, and trade tag slots. Do not promote weather or trade labels into cards, legends, or explanatory modules. |
| Distinguish analysis categories from market states | E-011, E-012 | Use portfolio analysis colors only for holding attribute visuals. Do not reuse market up/down tokens for analytics segmentation. |
| Keep analytics headers compact and actionable | E-015, E-016 | Use a 32px row header with a left accent, inline preference value, and compact right action rather than a large section title. |
| Keep analytics tables column-stable | E-017, E-018 | Header and rows must share the same column widths so fit, attribute, and value comparisons remain scannable. |
| Represent portfolio fit as compact sub-status labels | E-030, E-031 | Use the extracted 68x20 assessment indicator and 105x24 attribute label inside portfolio rows. Do not expand them into standalone cards, legends, or oversized chips. |
| Explain stock fit in a compact bottom sheet | E-032, E-033, E-070, E-071, E-072, E-073 | Use a 375px bottom sheet with portfolio stock sheet cells, attribute labels, fixed-column scoring details, and one neutral similar-stock action. Do not convert this into a full-screen profile or dashboard panel. |
| Keep preferred-stock discovery table-led | E-034, E-035, E-036, E-037 | Use compact title/context bars and a six-column header/row contract. Do not convert preferred-stock discovery into cards, tiles, or marketing-style recommendations. |
| Treat valuation as its own label language | E-038 | Use valuation-specific label colors and text. Do not reuse market up/down or portfolio category semantics for price valuation. |
| Keep stock health checks as diagnostic reports | E-039, E-040, E-041, E-042, E-043, E-044 | Compose health-check rows from fixed-width cells, then reveal detail sections as flat 375px report blocks. Do not convert diagnostics into cards, progress widgets, dashboards, or explanatory panels. |
| Keep realtime portfolio P/L compact and expandable | E-045 | Use the three-column profit summary as the stable header and reveal charts below it. Do not replace the module with separate metric cards or oversized dashboard charts. |
| Separate temporal state from financial state | E-020, E-021 | Use temporal current/future/past tokens only for calendar labels. Do not map them to market, error, success, or portfolio category semantics. |
| Keep event labels as metadata, not CTAs | E-022, E-023 | Event-name orange can mark financial calendar metadata without a filled surface, icon, or button treatment. Do not infer interactivity from color alone. |
| Keep event rows compact but bordered | E-024, E-025 | Event table rows may use a 4px bordered surface when they combine stock identity and multi-line event detail, but should remain narrow, dense, and data-led. |
| Use compact controls around event lists | E-026, E-027 | Calendar navigation and event filtering controls stay 28px high, outline-based, and label-led. Do not expand them into toolbar cards or oversized filter chips. |
| Keep event category selection as a bottom sheet grid | E-028, E-029 | Major-event category filters use compact filled options in a 375px bottom sheet. Do not turn them into a full-screen settings page or explanatory filter form. |
| Keep bottom-sheet chrome modular | E-063 | Use a 64px header for close/back/title variants and a 20px drag-handle strip when the sheet needs grab affordance. Do not rebuild these controls per sheet or add decorative sheet headers. |
| Keep bottom-sheet rows dense and command-led | E-064, E-065, E-066 | Use 58-59px full-width rows with 24px/32px utility icons, 18px labels, inset dividers, and compact right-side status/switch slots. Do not convert sheet commands into card rows or large settings panels. |
| Treat switch as a compact standalone control | E-078, E-064, E-059 | Use the extracted Switch for binary settings and broker import slots, preserving Android/iOS off/on geometry. Do not replace it with generic checkboxes, text toggles, or row-specific custom artwork. |
| Treat selection marks as standalone compact controls | E-079, E-067, E-064 | Use the extracted Selection Control for 20px checkbox/radio slots. Do not replace it with Switch, filled text options, row background changes, or generic browser-default controls. |
| Keep centered popups distinct from bottom sheets | E-080, E-067, E-029, E-054 | Use Popup Dialog for compact centered prompts with optional media and two footer actions. Do not reuse 375px bottom-sheet chrome, drag handles, safe-area structure, or sheet footer actions for these 292px dialogs. |
| Keep empty states section-level | E-085, E-080, E-083 | Use Empty State for non-modal no-content guidance on a 375px section/page surface. Compose the optional primary action from Button; do not turn Empty State into Popup Dialog, onboarding card, or a new button family. |
| Keep anchored bubbles directional and compact | E-082, E-080, E-027 | Use Global Bubble for target-attached contextual information with amber fill, dark text, directional arrow, and low shadow. Do not turn bubbles into popups, dropdown menus, or promotional badges. |
| Keep settings sheets compositional | E-067, E-068, E-069 | Build inventory settings sheets from Bottom Sheet Header, Bottom Sheet Cell, preview selectors, selection rows, and Bottom Sheet Footer Button where a submit action is required. Do not turn nested settings, sorting, display-mode selection, or watchlist assignment into full-screen pages or card stacks. |
| Keep portfolio sheet cells domain-specific | E-071 | Use Portfolio Stock Sheet Cell for stock identity, attribute tab summaries, and health-check title summaries inside portfolio bottom sheets. Do not expand generic Bottom Sheet Cell with analytics-specific columns or tab semantics. |
| Keep market filters compact and text-led | E-046 | Use a 40px strip with compact filled options; active state changes text color only. Do not inflate secondary market filters into large chips or segmented controls. |
| Keep inventory primary tabs compact | E-060, E-061 | Use a 37px primary tab strip with white active labels, gray inactive labels, and a chevron only where the source proves expandability. Do not convert primary inventory tabs into underlined web tabs, large chips, or segmented controls. |
| Persistent controls frame the task | E-001, E-003, E-007, E-008, E-047, E-086 | Top app bar, bottom navigation, and compact action pills remain anchored around the list or side context. Use the attached 38px black Floating Action Pill group only for watchlist quick actions; avoid page-level hero, card stacks, or dashboard chrome. |
| Keep add-holding entry points compact | E-049, E-050 | Use orange outline actions inside a flat `#252525` section; do not convert add/sync entry points into onboarding cards, upload panels, or large CTAs. |
| Keep add-holding forms sheet-based | E-054, E-055, E-056 | Use a compact 375px bottom sheet with 54px form rows, orange outlined controls, segmented stock type, and one 295x41 confirm action that switches from gray outline disabled to orange filled default. Do not convert add-holding into a full-page form, wizard, or card stack. |
| Keep broker identity container-led | E-048 | Use compact 46px rounded source containers with short centered labels; do not reinterpret broker source colors as product state or category colors. |
| Keep promotional badges compact and text-led | E-057, E-059 | Use 23px yellow gradient badges only for short promo or fee-discount labels. Do not turn them into CTAs, status chips, icons, banners, or glowing marketing tags. |
| Keep new-state badges separate from promotions | E-065, E-064 | Use the 42x20 red `New` badge only as a small status marker on new actions. Do not reuse the yellow Promotional Badge treatment or turn `New` into a marketing banner. |
| Keep broker import flows row-led | E-058, E-059, E-048, E-057 | Use flat 375px import headers and 132px broker rows with broker icon, optional promo badge, helper copy, compact action, and switch slot. Do not convert broker import into account cards, setup panels, or a full-page wizard. |
| Keep broker import menus utility-led | E-060, E-062 | Use the 42px broker import menu as a dense utility row with dropdown, sync/edit outline actions, and update metadata. Do not turn it into a toolbar card, banner, or explanatory settings panel. |
| Keep manual import table-led | E-051, E-052, E-053 | Use fixed-column 61px rows with compact value fields and a sticky stock identity column. Do not convert manual import into stacked forms or card-based entry. |
| Labels stay regular-weight and compact | E-003, E-005, E-007 | Use PingFang TC regular, mostly 11-18px. Do not introduce large display type or bold-heavy hierarchy for this screen class. |
| Data visualizations stay compact and explanatory | E-011, E-013 | Pair compact visuals with adjacent labels and values. Do not make charts decorative or oversized. |
