# 版面調整 Before／After 區塊格式

每一項修改一個區塊，最新一輪的放最前面。截圖用主機截圖；看圓角時用套用螢幕外形的版本，同一區塊不混用。

```
### <頁面>・<做了什麼>（第 N 輪，YYYY-MM-DD）
姿態與尺寸：外螢幕 466×678 pt／內螢幕橫向 951×669 pt／內螢幕直向 669×951 pt
說明：<一到三句：改了什麼、為什麼、套用在哪些姿態；沒改的姿態也說一句>

| 修改前（第 N-1 輪 或 日期） | 修改後（目前版本，YYYY-MM-DD 重拍） |
|---|---|
| <截圖> <一句說明> | <截圖> <一句說明> |
| <截圖> | <截圖> |

未變動：<截圖> <姿態> — <為什麼放這張（證明沒有回歸）>
待確認：<如果這項有要問設計師的事>
```

檢查清單（發布前）：

- [ ] 每張「修改後」都是目前版本；共用元件（直欄、按鈕、底色）改過就全部重拍
- [ ] 「修改前」標了輪次或日期
- [ ] 每個區塊有頁面、姿態、尺寸、一句為什麼
- [ ] 報告的問題編號沒有變動（已移除的保留編號）
- [ ] 待決事項有截圖與選項
