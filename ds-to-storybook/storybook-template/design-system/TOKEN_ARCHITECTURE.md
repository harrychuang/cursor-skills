## Prefix

Template projects use the prefix configured in `.storybook/project.config.ts`.
The starter baseline currently uses `--sbt-*`, and initialized projects should
choose their own prefix with `npm run init-template -- --name <project-name>
--prefix <token-prefix>`. `cm` is legacy source/reference language only, not a
template default.

## Layers

- `tokens/tokens-ref.css`: raw values only. Names describe hue, dark-to-light palette step, neutral step, raw size, radius, typeface, weight, opacity, or line-height value.
- `tokens/tokens-sys.css`: product-wide semantic roles. These tokens reference `--<prefix>-ref-*` only.
- `tokens/tokens-comp.css`: component slot roles. These tokens reference `--<prefix>-sys-*` only.
- `tokens/tokens.css`: import entry point in `ref -> sys -> comp` order.

## Naming Decisions

- The exported Chinese style names are treated as source labels, not final token names.
- Reference color numbers use dark-to-light ordering: smaller steps are darker and larger steps are lighter. `*-alpha-*` tokens are the exception; their trailing number describes opacity.
- Orange is `primary`; amber is `secondary` and event-badge color.
- `#1E1E1E`, `#252525`, `#333333`, and `#000000` form the dark app shell.
- Taiwan stock-market semantics are preserved: red is `market-up`, green is `market-down`.
- Main-force buy/weather signals receive `main-force-*` semantic roles even when they reuse red, so they are not confused with market-up price movement or generic error.
- `#FFD98A` and `#FF8A91` are modeled as main-force trade-tag roles for `隔日沖` and `短沖`; they are not promotional badges, portfolio attributes, or validation states.
- `#7E7873` is modeled as selected control and neutral floating action color.
- `#36A9EA`, `#F9A516`, `#D73152`, and `#808080` are modeled as portfolio analysis category colors, not market state colors.
- `#EA272D` and `#39B54A` are reused by `速配評估`, but system tokens name them as fit-assessment match and mismatch roles so the slot is not mistaken for price movement or generic success/error.
- `#EA272D` is also used as a portfolio fit score color in the stock sheet; it receives a score-specific system role instead of reusing `market-up`.
- The observed `#404040` subtle action surface is normalized to `#3D3D3D` / `--cm-ref-color-neutral-24` so it shares the neutral control step with compact outlines and event filter options.
- `#FFE2D4` and `#E5F9FF` are raw valuation label hues; system tokens name them as valuation states rather than market or portfolio category colors.
